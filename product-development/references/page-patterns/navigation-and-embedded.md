# 多层导航与嵌入内容

## `nested-tabs` 多层标签页

**适用**：模块内仍需二级/三级页签，并要求可深链访问。

**必备契约**

- 每层活动项由路由唯一决定；页签 key 使用稳定路由或业务 ID，不复制一份独立活动状态。
- 父路由定义默认子路由和无权回退；刷新、后退、前进和直接输入 URL 得到一致结果。
- 明确切换时是否保留筛选、滚动与编辑草稿；存在未保存修改时按设计提示离开。
- 标题、面包屑和页签名称来自同一份路由元数据。

**验证**：深链、刷新、历史前进后退、无权子页、默认重定向、未保存草稿、快速切换请求竞态。

## `embedded-content` 嵌入内容

**适用**：以 iframe 或受控容器嵌入第三方或独立子系统。

**必备契约**

- 嵌入地址由可信配置生成并校验协议、域名和路径；禁止直接拼接用户输入。
- 明确 CSP、`sandbox`、`allow`、跨域认证和 referrer 策略，只开放业务必需能力。
- `postMessage` 同时校验 `origin`、消息类型与载荷结构；请求/响应使用关联 ID，敏感数据不写入 URL。
- 提供加载、超时、拒绝访问和嵌入失败状态；必要时给出经授权的独立打开入口。
- 嵌入页的登录过期、主题、语言和高度同步有明确协议，监听器在卸载时清理。

**验证**：非白名单 URL、伪造消息、认证过期、加载超时、第三方拒绝嵌入、重复挂载、键盘可达性。
