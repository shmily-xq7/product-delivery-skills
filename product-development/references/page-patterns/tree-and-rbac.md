# 树表联动与权限矩阵

## `tree-table` 树表联动

**适用**：组织、分类、区域等层级树控制右侧列表或详情。

**必备契约**

- 节点使用稳定 ID，明确根节点、懒加载、是否包含后代、无子节点和禁用节点语义。
- 选中节点写入 URL 或可恢复状态；刷新后先恢复树路径，再加载关联表格，避免请求错误节点。
- 新增、移动、删除节点后同时刷新父节点计数、展开状态和右侧数据。
- 删除非空节点、形成循环、移动到无权节点等情况由服务端拒绝并返回可理解原因。

**验证**：深链恢复、懒加载失败、快速切换导致旧请求回写、空节点、移动与删除限制、无权节点。

## `rbac-matrix` 权限矩阵

**适用**：为角色分配菜单、资源、数据范围和动作权限。

**必备契约**

- 权限项以稳定 `permissionId` 表示，并区分菜单可见、页面访问、数据范围和动作授权。
- 父子勾选的联动规则必须显式定义；半选状态只表达聚合结果，不能被当作独立权限提交。
- 加载时保留服务端版本号；保存使用版本或 ETag 做并发控制，冲突时要求重新加载并比较差异。
- 高风险权限显示影响范围并二次确认；前端展示结果不能替代服务端鉴权。
- 提交差异集或完整快照必须与 API 契约一致；成功后重新读取服务端结果作为最终状态。

**验证**：父子联动、半选、搜索后勾选、无权项、并发修改冲突、保存失败、重新加载一致性。
