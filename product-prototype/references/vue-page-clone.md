# Vue 页面复刻衔接

本文件补充 HTML 复刻流程到 Vue 正式代码之间的框架衔接。业务字段和交互规则仍以产品设计、模块设计为准。

## 分析

记录页面区块、Element 组件映射、可复用项目组件、路由/面包屑、插槽、自定义单元格、弹窗和响应式断点。先确认目标项目是 Vue 2 + Element UI 还是 Vue 3 + Element Plus。

## 实施

- 读取 `product-development` 的通用开发契约及唯一匹配的 Vue profile。
- 优先复用目标项目现有布局、表格、分页、权限和请求封装。
- 先完成结构和信息层级，再对齐间距、颜色、字体与状态。
- 生产代码不内置截图中的示例数据；用 Props、service 或 fixture 隔离演示数据。

## 验证

- 对比主要分辨率下的区块位置、尺寸、留白、颜色和文字层级。
- 验证 loading、空态、错误态、禁用态、权限态和弹窗校验。
- 验证路由直达、刷新、前进后退、标签切换和面包屑。
- 运行项目的 lint、类型检查（如适用）、构建和 Playwright。
