# 页面原型与复刻

> 定位：把「界面长什么样」**可视化成图**。产物是线框图或静态 HTML，不是产品设计文档，也不是可上线的代码。

## 1. 何时使用

| 场景 | 用哪个 |
|---|---|
| 产品设计文档里要插「页面布局设计详情」 | **ASCII 线框** |
| 要快速给需求方看个能点的静态页面 | **单文件 HTML 原型** |
| 已有一个页面/设计稿，要在别处还原出同样的界面 | **页面复刻** |
| 要在评审前把交互布局讲清楚 | ASCII 线框（比文字快，比真代码便宜） |

## 2. ASCII 线框生成规范

参考 `references/ascii-ui-generator.md`（Ant Design 风格 ASCII 页面图生成规范）。

**硬规则**
- **页面线框图用 ASCII 字符**（`+ - | = _ / \ # *`）绘制，**不使用 Unicode 框线字符**（`┌ ─ │ └` 等）。理由：ASCII 宽度恒定、无缺字形风险、能安全经 DOCX 转换
- **允许**用单宽几何 / 勾选符号做状态标记：`▼ ▽ ▲ △ ■ □ ▪ ▫ ● ○ ◆ ◇ ◀ ▶ ◁ ▷ ☐ ☑ ☒ ✓`
- ⚠️ 其中 `▼ □ ● ○ ■ ◆ ◀ ▶` 属 East Asian **Ambiguous** 宽度 —— 在部分中日韩等宽字体下会占 2 列而致错位；若目标阅读环境如此，改用纯文字标记（`v` / `[ ]` / `[x]` / `(o)` / `( )`）。`☐ ☑ ☒ ✓ ▪ ▫` 是真正单宽，无此风险
- **几何符号不享受 DOCX 导出保证**：要交付 Word 时回到纯 ASCII 字符
- **文件树 / 流程示意不受此限**：可用 Unicode 连接符（`│ ├ └`）——树形结构不追求像素级对齐，且竖线用 ASCII `|` 观感明显更差
- **禁止 emoji 充当图标**（`🔄 📝 🗑️ ✅ ❌ 🆕` 等）；界面元素用文字标签、ASCII 符号或上条允许的几何符号表达（`[编辑]`、`(o)`、`v`、`▼`、`☑`）
- 行宽 **≤ 100 列**，等宽字体下必须对齐
- 标注主要区域标题与关键按钮/字段名称
- 页面含多个主视图或弹窗时，**每个视图单独给图**
- 页面结构调整后必须**同步更新**对应的 ASCII 图（这是最容易腐化的产物）

**流程**：分析页面结构 → 设计布局 → 优化（对齐、留白、层级）→ 输出。

## 3. 单文件 HTML 原型

参考 `references/html-page-dev.md`（最完整的 HTML 页面生成规范）。

**技术约定**
- 单文件 HTML + Bootstrap 5，不引入构建链
- 配色统一走 **CSS 变量**，便于整体换色
- 覆盖这些区块的规范细则：面包屑、页面标题、搜索区、表格、分页、操作按钮区
- 导航栏用 **Web Components** 封装，避免多页复制粘贴

**与正式前端的关系**：本原型用于**演示与评审**，不是交付代码。若原型被认可，正式实现走 `product-development`（React + AntD），**视觉 token 必须取自 `product-ui-spec`**，不要直接把 Bootstrap 的默认色带进正式项目。

## 4. 页面复刻流程（四阶段）

参考 `references/html-page-clone.md`。

| 阶段 | 动作 | 产出 |
|---|---|---|
| 1 分析 | 拆解源页面的**结构层级、区块划分、组件构成、交互点** | 结构清单 |
| 2 实施 | 按「由外到内、由骨架到细节」逐层搭建 | 可运行页面 |
| 3 验证 | 与原页面逐区块对比（布局、间距、配色、状态） | 差异清单 |
| 4 检查清单 | 逐项过检查清单（响应式、空态、交互态、可访问性） | 复刻完成确认 |

**关键原则**：先对齐**结构与信息层级**，再调视觉细节。反过来做会反复返工。

**注意**：本 skill 只覆盖 **HTML 页面复刻**流程。Vue 页面复刻**不在本族范围内**——本族技术栈基线为仅 React 栈（见 `product-development`）。若项目确实需要复刻 Vue 页面，请沿用同一套「分析 → 实施 → 验证 → 检查清单」四阶段方法自行执行，产物落在目标项目的 Vue 工程内。

## 5. 完成前自检清单

- [ ] 页面线框图未混入 Unicode 框线，行宽 ≤ 100 列，等宽对齐
- [ ] 线框图中无 emoji；状态标记只用 ASCII 文字标记或白名单内的单宽几何符号（`▼ □ ☑ ☐ ● ○` 等）
- [ ] 每个主视图 / 弹窗都有独立图
- [ ] 图中标注了区域标题与关键按钮/字段
- [ ] HTML 原型配色走 CSS 变量，未散落硬编码色值
- [ ] 复刻时先对齐结构再对齐视觉
- [ ] 若原型将转为正式实现，已声明 token 取自 `product-ui-spec`
