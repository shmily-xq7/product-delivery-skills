任务：生成产品设计文档中 `指定页面` 内容，并保存到已有的产品设计文档中对应章节中。

输入：`指定页面` 的名称
原始需求：`项目战略规划/原始需求.md` 中的 `指定页面` 内容
产品设计规范：`product-design/references/product-design-spec.md`（产品设计规范 V2，属 skill `product-design`）
输出：产品设计文档 `项目战术执行/00_产品设计文档.md`
      （该文档 = **前置章节**「需求说明 / 设计初始化 / 功能清单，按需」+ **主体章节**「业务流程 / 页面清单 / 功能设计详情 / 全局检查」；**子阶段产出不单独建文件**）

流程：
  1. 深度分析原始需求中的 `指定页面` 需求
  2. 按照产品设计规范的「页面设计详情」要求进行设计
  3. 生成 `指定页面` 的设计内容；如果设计内容已经存在，则根据内容情况进行更新或补充
  4. 结果保存到产品设计文档中对应章节

要求：
  - 严格按照产品设计规范中的要求进行设计
  - 页面设计中的每个 tab 页、弹窗等都不要遗漏
  - 遵守 V2 排版约束：按钮操作不单独成表；字段规格只在「字段字典」出现一次；每个页面/弹窗尽量 ≤2 张表
  - 验收标准：每个页面/弹窗/步骤/tab 都要有「验收标准」小节，条目形如 `AC-<模块缩写>-<两位序号>`（如 `AC-USER-01`），**全文唯一**，用编号列表承载；新增页面时接续该模块已有的最大序号编号
  - Mermaid 图遵守 `product-workflow/references/mermaid-guide.md`；ASCII 线框遵守 `product-prototype/references/ascii-ui-generator.md`
  - 阶段检查：产出后运行 skill `product-design` 的 `scripts/validate_design_doc.py`（含 C12 编号格式 / C13 编号唯一 / C14 每页至少 1 条 AC）
